소각로 운영관리 · 아이폰 위젯

1. ZIP을 풀고 어제 사용한 GitHub 저장소의 같은 위치에 index.html, sw.js, manifest.webmanifest, incinerator-widget.js를 올립니다.
2. GitHub Pages 배포가 끝나면 일정을 등록해 온 화면을 다시 엽니다. 홈 화면 앱에서 일정을 등록했다면 그 앱에서 진행하세요. 같은 주소와 저장 공간의 기존 기록을 그대로 읽습니다.
3. 아이폰에 Scriptable을 설치합니다. 일정 앱의 “처음 연결하기”에서 “위젯 코드 복사”를 누르고, Scriptable에서 +를 눌러 붙여넣은 뒤 스크립트 이름을 “소각로 위젯”으로 지정합니다.
4. 일정 앱에서 “위젯 업데이트”를 누릅니다. Scriptable이 열리면 오늘과 내일 일정 미리보기가 표시됩니다.
5. 아이폰 홈 화면 빈 곳 길게 누르기 → 편집 → 위젯 추가 → Scriptable. 중간 크기를 추가한 뒤 위젯을 길게 눌러 위젯 편집 → Script → “소각로 위젯”을 선택합니다.
6. 일정을 추가·수정·삭제한 뒤에는 “위젯 업데이트”를 누르세요. 홈 화면 반영 시점은 iOS가 정합니다.

작은 위젯은 오늘, 중간 위젯은 오늘·내일 일정을 보여줍니다. 제목은 최대 7글자이며 넘치는 일정은 건수로 표시됩니다. 위젯을 누르면 등록 화면이 있는 웹 주소가 열립니다. 홈 화면에 설치한 웹 앱과 Safari의 저장 공간은 다를 수 있으니 일정 편집 및 갱신은 기존에 기록하던 화면에서 진행하세요.

위젯으로 보낸 일정은 아이폰에 저장됩니다. GitHub에는 앱 파일만 올립니다. 상세 내용은 위젯으로 보내지 않습니다.
